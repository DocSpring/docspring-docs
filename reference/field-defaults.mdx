You can add fields to a template with
[Add fields to a template](/docs/api/#tag/templates/post/templates/{template_id}/fields), and change them with
[Update a template's fields](/docs/api/#tag/templates/put/templates/{template_id}/fields). Every property is optional:
a field without a `page` goes on page 1, and the field's other properties have the following default values:

{/* The defaults are stored with the template editor's camelCase names. These are the settings of API v2's Field. */}

export const settingNames = Object.keys(
  openapi.components.schemas.Field.properties,
).filter((name) => !["id", "name", "page", "acroform_name"].includes(name));

export const apiDefaults = (defaults) =>
  Object.fromEntries(
    Object.entries(defaults)
      .map(([key, value]) => [
        key.replace(/[A-Z]/g, (letter) => `_${letter.toLowerCase()}`),
        value,
      ])
      .filter(([name]) => settingNames.includes(name)),
  );

Properties that are shared by every field with the same name (such as `type`, `required`, and `default`) use the following default values.
Note that new fields are required by default (`"required": true`).

export const sharedFieldDefaults = apiDefaults(fieldDefaults.shared_field);
