## Required Properties

When you [add fields to a template](/docs/api/#tag/templates/post/templates/{template_id}/fields), every property is
optional: a field without a `page` goes on page 1, and the others use their [default values](/docs/reference/field-defaults/).
To [change fields](/docs/api/#tag/templates/put/templates/{template_id}/fields), send each one's `id` with the settings
to change.

## Field Schema

This is a field as [List a template's fields](/docs/api/#tag/templates/get/templates/{template_id}/fields) returns it,
with every property, its type and its allowed values. Adding and changing fields take the same properties, except the
read-only ones. The same settings are in template `defaults` and a submission's `field_overrides`. API v1 names them in
camelCase (`fontSize` instead of `font_size`).
