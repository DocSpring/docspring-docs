Connect DocSpring to your apps and automation workflows to generate PDFs, collect signatures, and store completed documents.

## Getting started

For third-party apps, create a DocSpring API token and enter its token ID and secret in the app's connection settings. AWS S3 connections are configured in DocSpring under **Integrations → Manage S3 connections**.

## Build your own integration

Use the REST API or an official client library to generate PDFs from your application. Webhooks notify your app when PDFs finish processing or signing events occur.
