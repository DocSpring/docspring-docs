## Changelog

### 0.1.3 <span class="ml-2.5 relative -top-0.5"><Badge text="Latest" variant="success" size="small"></Badge></span>

<div class="mt-2.5 text-sm text-gray-500 dark:text-gray-400">
  Released on Oct 29, 2026
</div>

- Works on a page whose Content-Security-Policy doesn't allow inline styles
  (no `'unsafe-inline'` in `style-src`). The editor's iframe no longer has a
  `style` attribute, and the modal's CSS is no longer a `<style>` element. See
  [Content Security Policy](/docs/forms/js-libraries/content-security-policy/).
- No longer logs a Content-Security-Policy error in Chrome on a page whose
  `script-src` doesn't allow `'unsafe-inline'`. The jQuery it includes tested
  for an old Internet Explorer event by setting an `onfocusin` attribute, which
  the policy blocked, and the page sent a report for it if it collects them.

### 0.1.2

<div class="mt-2.5 text-sm text-gray-500 dark:text-gray-400">
  Released on Aug 28, 2026
</div>

- Removed the `AU` region option. The AU region has been shut down, so `region`
  now accepts `US` or `EU`.

### 0.1.1

<div class="mt-2.5 text-sm text-gray-500 dark:text-gray-400">
  Released on Jun 25, 2026
</div>

- Added `region`, `host`, `appHost`, and `apiHost` options for configuring
  US, EU, AU, and enterprise deployments.
- Fixed `editorURL` message origin handling for custom embedded editor URLs.

### 0.1.0

<div class="mt-2.5 text-sm text-gray-500 dark:text-gray-400">
  Released on Jun 25, 2026
</div>

- Initial release of `template_editor.js`
- Added `DocSpring.createTemplateEditor`
- Added inline and modal iframe support
- Added per-embed feature overrides
- Added event callbacks for load, save, document update, and version actions
- Added customizable done button support with an `onDone` callback
