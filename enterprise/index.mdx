DocSpring Enterprise runs DocSpring on your own infrastructure. DocSpring is a
Rails application, released as a Docker image for both AMD64 and ARM64.

## Requirements

- PostgreSQL 14 or later. We run PostgreSQL 17 and recommend it for new installs.
- Redis 6.2 or later.
- A file storage service, such as AWS S3 or Google Cloud Storage.
- Your DocSpring license key and the credentials for DocSpring's Docker
  registry. We send these to you by email.

## Deployment options

### AWS via Convox

[Convox](https://www.convox.com/) is an open source PaaS that runs in your own
AWS account. It sets up a Kubernetes cluster on
[EKS](https://aws.amazon.com/eks/) and uses
[Terraform](https://www.terraform.io/) to manage your infrastructure config and
state.

Convox offers a hosted Console service and paid support plans, but the
[Convox Rack](https://github.com/convox/convox) itself is open source and free
to use. Our install script sets up a free, self-hosted Convox Rack on AWS. You
don't need the Convox Console.

<LinkCard
  title="Install DocSpring on AWS with Convox"

<Aside type="tip">
  Let us know if you need our Convox install script to support another cloud,
  such as Google Cloud, DigitalOcean or Microsoft Azure.
</Aside>

### Helm charts for Kubernetes

If you already run a Kubernetes cluster, you can set up DocSpring with our Helm
charts:
[DocSpring/docspring_helm_chart](https://github.com/DocSpring/docspring_helm_chart).

### Aptible

[Aptible](https://www.aptible.com/) is a PaaS for deploying secure and
compliant infrastructure. See
[DocSpring/docspring-enterprise-aptible](https://github.com/DocSpring/docspring-enterprise-aptible)
for setup instructions.
