Our API specification is published as a [Postman](https://www.postman.com) collection.

<Aside>
  The Postman collection covers [API v1](/docs/api/v1/). For API v2, import our
  [OpenAPI schema](/docs/api-guide/openapi-schema/) into Postman, or try
  requests in the [API reference](/docs/api/).
</Aside>

## Postman Collection

<LinkCard
  title="DocSpring Postman Collection"
  href="https://postman.docspring.com"
  description="Use our Postman collection to try out the DocSpring API"
/>

You can [download the Postman app](https://www.postman.com/downloads/) to try out API requests using an [API token](https://app.docspring.com/api_tokens).
