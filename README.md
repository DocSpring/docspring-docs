# DocSpring Documentation

This repository contains the public documentation for [DocSpring](https://docspring.com), a document automation platform. Fill PDF forms, generate PDFs and Word documents from templates, and collect e-signatures with one API.

## 📚 About

This is a mirror of DocSpring's documentation content. It is updated automatically whenever we deploy new documentation, and we welcome contributions through GitHub. The documentation is built using [Astro Starlight](https://starlight.astro.build/) and is published at [docspring.com/docs](https://docspring.com/docs/).

## 🤝 Contributing

We welcome contributions to improve our documentation! Here's how you can help:

1. **Edit a page**: Click the "Edit this page" link at the bottom of any documentation page on [docspring.com/docs](https://docspring.com/docs/)
2. **Fork this repository**: Make your changes in a new branch
3. **Submit a Pull Request**: Describe your changes and why they improve the documentation

### What we're looking for:

- ✅ Typo fixes and grammar improvements
- ✅ Clarifications to existing content
- ✅ Corrections to outdated information
- ✅ Better explanations of complex concepts

### Guidelines:

- Keep the existing structure and formatting
- Follow the existing writing style
- Test any code examples you add
- For major changes, please open an issue first to discuss

## 🔄 Sync Process

We don't merge pull requests in this repository directly, because it is overwritten with our main documentation source on every documentation deploy. When we accept your PR:

1. We apply your changes to our main documentation source, crediting you as a co-author
2. We close your PR with a link to the change
3. Your changes appear on [docspring.com/docs](https://docspring.com/docs/) and in this repository after our next documentation deploy
